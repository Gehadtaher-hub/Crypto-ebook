Course Laboratory

From Security Concepts to Verifiable Results

Each lab follows the same scientific workflow: predict the result, run the experiment, inspect the evidence, explain the security meaning, and record a conclusion.

Before the lab

Read the matching lecture and write a prediction.

During the lab

Change one variable at a time and preserve the output.

After the lab

Explain what the result proves—and what the experiment does not prove.

Laboratory Rules

  1. Use only sample data and authorized systems.
  2. Record inputs, outputs, assumptions, and unexpected behavior.
  3. Distinguish confidentiality, integrity, authenticity, and availability.
  4. Never treat encoding as encryption or a raw hash as password protection.
  5. Submit evidence, analysis, and a concise conclusion.
